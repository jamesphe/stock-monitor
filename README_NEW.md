# 股票信号监控系统（Alpine.js + TailwindCSS 版本）

## 项目简介

这是一个股票信号监控系统，使用Alpine.js和TailwindCSS构建前端，Flask提供后端API服务。系统可以监控股票价格、成交量、技术指标等信号，并在满足条件时发送企业微信通知。

## 功能特点

- 支持多种监控条件：价格突破、成交量异常、RSI指标、均线交叉、MACD等
- 可配置企业微信机器人通知
- 响应式设计，适配桌面和移动设备
- 可视化股票数据图表
- 实时告警历史记录

## 安装和使用

### 依赖安装

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python api.py
```

启动后访问 http://localhost:5000 即可打开监控系统。

## 使用指南

1. **配置企业微信通知**：在系统配置中填入企业微信机器人的Webhook地址
2. **添加监控股票**：
   - 输入股票代码和名称（可选）
   - 配置监控条件：价格突破、成交量、RSI、均线交叉、MACD等
   - 点击"添加监控"按钮
3. **查看监控状态**：
   - 在监控列表中查看已添加的股票
   - 点击"查看"按钮可以查看股票数据图表
   - 点击"删除"按钮可以移除监控项

## 数据源说明

系统支持两种数据源：
- **AKShare**：优先使用，提供更全面的数据
- **备选数据源**：当AKShare不可用时，使用新浪财经API获取数据

## 技术实现

- **前端**：Alpine.js + TailwindCSS + Chart.js
- **后端**：Flask API + pandas + pandas-ta
- **数据源**：AKShare/新浪财经API
